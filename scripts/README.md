
# Automation Scripts

This directory contains Python automation scripts.

## Planned Scripts

### Video Generator
Manage video generation requests.

### Video Editor
Combine and edit video clips.

### Audio Processor
Process ASMR audio and dialogue.

### Subtitle Generator
Create subtitles for videos.

### Character Manager
Organize character reference images.

### Export Manager
Export videos in different formats.

## Technologies
- Python
- MoviePy
- FFmpeg
