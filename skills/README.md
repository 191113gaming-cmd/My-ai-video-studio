
# Claude AI Skills

This directory contains AI skills for My AI Video Studio.

## Planned Skills

### 1. Video Generation
Generate videos from text and images.

### 2. Character Consistency
Maintain the same character appearance across scenes.

### 3. Video Editing
Automatically organize and edit video clips.

### 4. Story Writing
Create engaging stories and scene-by-scene prompts.

### 5. YouTube SEO
Generate titles, descriptions, tags and hashtags.

### 6. Audio Generation
Plan ASMR sounds, dialogue and sound effects.

## Skill Format
Each skill will contain a SKILL.md file.
