# Character Consistency Manager

## Main Objective
Maintain the same recognizable characters throughout a video.

## Character Reference
Use the user's original character reference images as the primary identity source.

## Identity Rules
- Preserve facial structure.
- Preserve eye shape.
- Preserve nose and lips.
- Preserve skin tone.
- Preserve age appearance.
- Preserve body proportions.
- Avoid random face changes.
- Avoid character redesign.

## Clothing Rules
- Do not randomly change outfits.
- Keep clothing consistent between connected scenes.
- Change clothing only when requested.
- Regional clothing changes must be intentional.

## Scene Consistency
Every scene must maintain:
- Same character identity
- Same hairstyle unless specified
- Same outfit unless specified
- Consistent proportions
- Consistent animation style

## Output
Create:
1. Character descriptions
2. Character reference instructions
3. Scene consistency checklist
4. Image generation prompts
5. Video generation prompts
