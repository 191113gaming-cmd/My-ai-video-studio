
# My AI Video Studio

An open-source AI video production and editing studio.

## Vision
Create a mobile-friendly AI video production workflow.

## Main Features
- Text to Video
- Image to Video
- Character Consistency
- Character Animation
- AI Lip Sync
- ASMR Audio Workflow
- Video Editing
- YouTube Shorts
- Long-form Videos

## AI Tools
- Wan 2.2
- LTX Video
- ComfyUI
- HunyuanVideo
- CogVideoX
- AnimateDiff
- MuseTalk
- MoviePy
- FFmpeg

## Project Structure
- docs/
- skills/
- workflows/
- scripts/
- config/

## Requirements
- Open-source tools
- No paid APIs by default
- GPU requirements must be documented
- Mobile-friendly interface
- Secure configuration

## Status
Project setup in progress.
